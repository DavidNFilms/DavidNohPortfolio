Minute.

A personal desk companion built and used only by David Noh. Last updated October 11, 2026.

Policy

What Minute accesses

With the developer's permission, Minute reads events from, and creates or updates events in, the developer's own Google Calendar so the day's schedule can be shown on a desk display and focus blocks can be added from it. Minute is not offered to the public.

How data is used

Calendar data is processed only on the developer's own computer and shown on the developer's own display. It is not sold, shared, sent to third parties, or used for advertising. Google sign-in tokens are stored only on that computer.

Minute's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access & contact

Access can be removed at any time at myaccount.google.com/permissions. Questions: davidnoh0513@gmail.com.
